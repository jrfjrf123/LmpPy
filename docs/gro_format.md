# .gro 文件格式说明

扩展名为 `.gro` 的文件包含 **Gromos87 格式的分子结构**。通过简单拼接多个 gro 文件，可将其用作轨迹。

> **注意**：LmpPy 读取 gro 时只保留标题字符串本身（`scripts/build_cg_system.py:62` 的 `title = lines[0].strip()`），**不解析**其中的 `t=` 时间值。

## 示例文件

```
MD of 2 waters, t= 0.0
    6
    1WATER  OW1    1   0.126   1.624   1.679  0.1227 -0.0580  0.0434
    1WATER  HW2    2   0.190   1.661   1.747  0.8085  0.3191 -0.7791
    1WATER  HW3    3   0.177   1.568   1.613 -0.9045 -2.6469  1.3180
    2WATER  OW1    4   1.275   0.053   0.622  0.2519  0.3140 -0.1734
    2WATER  HW2    5   1.337   0.002   0.680 -1.0641 -1.1349  0.0257
    2WATER  HW3    6   1.326   0.120   0.568  1.9427 -0.8216 -0.0244
   1.82060   1.82060   1.82060
```

## 文件结构（从上到下）

| 行 | 内容 | 格式 |
|---|---|---|
| 第 1 行 | **标题字符串**（自由格式；GROMACS 惯例可在 `t=` 后跟时间 ps，但 LmpPy 不解析该值） | 自由格式字符串 |
| 第 2 行 | **原子数量** | 自由格式整数 |
| 第 3 ~ (N+2) 行 | **每个原子一行**（固定格式，见下文） | 固定列宽格式 |
| 最后 1 行 | **盒子向量**（自由格式，空格分隔的实数） | 自由格式实数 |

## 盒子向量说明

```
v1(x)  v2(y)  v3(z)  v1(y)  v1(z)  v2(x)  v2(z)  v3(x)  v3(y)
```

- 最后 6 个值可以省略（省略时设为零）
- **GROMACS 仅支持** `v1(y) = v1(z) = v2(z) = 0` 的盒子

---

## 原子行的固定格式

### 精度说明

- **默认格式**：每个字段 8 位宽度，坐标 3 位小数，速度 4 位小数
- **可选格式**：（目前仅 `trjconv` 支持）可使用任意小数位数，格式为 `n + 5` 位总宽度，`n` 位小数（速度 `n + 1` 位小数）。读取时会根据小数点间距自动推断精度。

### 各列含义（从左到右）

| 列 | 内容 | 格式 |
|---|---|---|
| 1 | **残基编号**（Residue number） | 5 位，整数 |
| 2 | **残基名称**（Residue name） | 5 个字符 |
| 3 | **原子名称**（Atom name） | 5 个字符 |
| 4 | **原子编号**（Atom number） | 5 位，整数 |
| 5 | **位置 x**（Position x，单位 nm） | 8 位，3 位小数 |
| 6 | **位置 y**（Position y，单位 nm） | 8 位，3 位小数 |
| 7 | **位置 z**（Position z，单位 nm） | 8 位，3 位小数 |
| 8 | **速度 x**（Velocity x，单位 nm/ps 或 km/s） | 8 位，4 位小数 |
| 9 | **速度 y**（Velocity y） | 8 位，4 位小数 |
| 10 | **速度 z**（Velocity z） | 8 位，4 位小数 |

### C 语言格式

```c
"%5d%-5s%5s%5d%8.3f%8.3f%8.3f%8.4f%8.4f%8.4f"
```

### 备注

- 单独的分子或离子（如水分子 `WATER`、氯离子 `Cl-`）被视为**残基**。
- 如需在不使用 GROMACS 库的情况下自行编写程序输出此类文件，可使用上述 C 语言格式。
